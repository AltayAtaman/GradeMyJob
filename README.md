# GradeMyJob 🎯

> **Know your fit, before you commit.**

Official landing page for **GradeMyJob** — the AI-powered cross-browser extension that analyzes job postings in real time, parses tech stacks, isolates hard vs. preferred qualifications, and calculates candidate fit.

🌐 **Live Site:** [https://AltayAtaman.github.io/GradeMyJob/](https://AltayAtaman.github.io/GradeMyJob/)

---

## Tech Stack

* **Framework:** React 18 & TypeScript
* **Bundler:** Vite
* **Styling:** Tailwind CSS & Lucide React
* **Deployment:** GitHub Pages (Automated via GitHub Actions)

## Local Development

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
